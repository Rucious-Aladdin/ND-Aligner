ND-Aligner

A neural discriminative forced aligner with asymmetric locality constraints
Suseong Kim, Jio Gim, Young-Joo Suh · POSTECH

Code Derivation note

ND-Aligner places every word and phone of a known transcript in time, learning to do so from paired speech and text alone — with no frame-level boundary labels and no pronunciation dictionary.

Using it

git clone https://github.com/Rucious-Aladdin/ND-Aligner.git
cd ND-Aligner && uv sync --locked
scripts/build_fb_kernel.sh && scripts/build_mas_dp.sh
aligner.align_to_textgrid(
    wav_paths=["utt.wav"],
    texts=["She had your dark suit in greasy wash water all year."],
    output_dir="./textgrids",
)
Audio is drawn from TIMIT, Buckeye, and VCTK. The alignments shown are the model's own output, not corrected by hand.
